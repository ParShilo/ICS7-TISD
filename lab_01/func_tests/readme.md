# Тесты для лабораторной работы № 1 по дисциплине «типы и структуры данных».

## Входные данные
Два числа, введённые в виде строки длиной до 100 символов в стандартном или экспоненциальном виде.

## Выходные данные
Одно вещественное число в виде результата умножения двух введённых чисел в экспоненциальной форме или сообщение об ошибке.

## Позитивные тесты:
1. 1 * 1;
2. 0 * 0;
3. Переполнение разряда;
4. Положительное целое число на отрицательное целое число;
5. Умножение целых отрицательных чисел;
6. Умножение вещественных чисел в экспоненциальной форме;
7. Умножение вещественных чисел не в экспоненциальной форме;
8. Умножение чисел с лидирующими незначащими нулями;
9. Умножение чисел с конечными незначащими нулями;
10. Умножение чисел с различными знаками экспоненты;
11. Умножение числа с 35 символами мантиссы на число с 40 символами мантиссы (округление);
#   369754668708670912673366711211644762738183019002034417648488326565889256211
# 0.3697546687086709126733667112116447627382E+75
12. Умножение чисел с пятизначной экспонентой; 

## Негативные тесты:
1. Пустой ввод;
2. Невалидный ввод;
3. Несколько знаков мантиссы;
4. Несколько точек;
5. Несколько знаков экспоненты;
6. Мантисса > 35 символов при вводе первого числа;
7. Мантисса > 40 символов при вводе второго числа;
8. Экспонента > 5 символов при вводе числа;
9. Отсутствие мантиссы перед экспонентой;
10. Несколько знаков (+-) перед экспонентой;
11. Результирующий порядок > 99999;
12. Результирующий порядок < -99999;
